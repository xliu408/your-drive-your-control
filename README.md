# Your Drive. Your Control.

Group 11 — Social Marketing for Health Communication

This is a simple eight-page website for a texting-and-driving prevention campaign.

## Pages

Home, About Us, Services, Facts & Statistics, Social Media, Support Us, Contact Us, and References.

## Before publishing

1. Replace the temporary file `assets/logo.png` with the actual campaign logo you uploaded (keep the filename `logo.png`).
2. In `contact.html`, replace `[Add your group's shared email before submitting]` with your group's actual contact information.
3. Double-check the group member names in `about.html` and revise if needed.
4. Open `index.html` locally to preview the website, then test the buttons, quiz, video links, and mobile menu.
5. Google Maps and YouTube embeds require an internet connection.

## Publish free on GitHub Pages

1. Make a public GitHub repository named `your-drive-your-control`.
2. Upload all of the files in this folder (not the enclosing folder).
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, `main`, and `/(root)`.
5. Save. Your site will appear at `https://YOUR-USERNAME.github.io/your-drive-your-control/` after deployment.

The pledge and quiz run in the browser. They do not save responses or collect contact information.

HTML, CSS and vanilla JavaScript only; no build tools or paid services are required.
